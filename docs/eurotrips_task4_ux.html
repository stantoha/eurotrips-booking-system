МЕТА ДОСЯГНУТА
📊 Зведення болів — пріоритет для MVP 8 критичних точок
🔴 БЛОКЕРИ (вирішити в MVP)
1. Конвертація ліда → бронювання не автоматична — подвійне введення даних
2. Відсутня нетто-ціна для агента в каталозі — помилки в комунікації з клієнтом
3. Live-доступність місць відсутня — ризик подвійного бронювання
4. Ліди з різних каналів не зведені — частина лідів губиться
🟡 FRICTION (вирішити в Release 2)
5. Немає бази збережених клієнтів агента — ручне введення щоразу
6. Рахунки формуються в Excel, відправляються вручну
7. Немає сповіщень про зміну статусу для агента
8. Лист-підтвердження відправляється вручну менеджером
