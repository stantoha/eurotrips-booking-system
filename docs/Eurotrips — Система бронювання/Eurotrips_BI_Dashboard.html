🔧 Специфікація KPI для Dashboard.tsx (Frontend)

⚙️KPI метрики — формули, джерела даних, порогові значення
KPI Назва (UK) Формула API endpoint Threshold (🟢/🟡/🔴) Тип візуалізації
1. Tour Fill Rate Заповненість туру booked_seats / total_seats × 100 GET /tours/:id/stats 🟢 ≥85% · 🟡 60–84% · 🔴 <60% Progress bar + % числом
2. Lead Conversion Конверсія лідів leads_converted / total_leads × 100 GET /leads/stats 🟢 ≥35% · 🟡 20–34% · 🔴 <20% Gauge chart / велика цифра
3. Avg Check (EUR) Середній чек total_revenue / confirmed_bookings GET /bookings/stats 🟢 ≥280€ · 🟡 200–279€ · 🔴 <200€ KPI card + trend sparkline
4. Revenue by Channel Дохід по каналу SUM(booking.price) GROUP BY source_channel GET /analytics/revenue Ціль: agent ≥30% від total Doughnut chart (direct/agent/corp)
5. Net Margin % Маржа туру (price - cost_price) / price × 100 GET /tours/:id/finance (admin only) 🟢 ≥15% · 🟡 8–14% · 🔴 <8% Bar chart (по напрямках)
6. Active Bookings Активних бронювань COUNT WHERE status IN (confirmed, awaiting_payment, partial) GET /bookings?status=active Динамічний — без жорсткого порогу KPI card + зміна за тиждень
7. Agent Commission Pool Нараховано комісій SUM(booking.price × commission_rate) WHERE status=confirmed GET /finance/commissions Інформаційний KPI KPI card (тільки для admin/director)
8. Tours Ready to Depart Готових до виїзду COUNT WHERE status=ready_to_depart AND depart_date ≤ now+7d GET /tours/upcoming 🔴 якщо <72год і не ready Alert list / countdown
