🔑 Overlay-паттерн карток
Картки турів = фото на весь блок + кольоровий блок overlay в нижній частині (cyan/red/blue/gold). Текст і кнопки — у цьому overlay. Це головний UI-паттерн сайту.
💊 Pill-кнопки скрізь
Всі кнопки — border-radius: 9999px (pill). Немає квадратних кнопок взагалі. Розміри різні але форма завжди capsule. Дати на картках — теж pill chips (білі).
📐 Кольори по контексту
Cyan = первинна дія (nav active, hero CTA). Red = вторинна CTA ("Докладніше", "Всі тури", "ВХІД"). Gold + Blue = контентні категорії. Розподіл чіткий.

TourCard.tsx · React компонент
type OverlayColor = 'cyan' | 'red' | 'blue' | 'gold'

const overlayClasses: Record<OverlayColor, string> = {
  cyan:  'bg-brand-cyan',
  red:   'bg-brand-red',
  blue:  'bg-brand-blue',
  gold:  'bg-brand-gold',
}

export const TourCard = ({ tour, color }: {
  tour: Tour; color: OverlayColor
}) => (
  <div className="relative rounded-[10px] overflow-hidden">
    <img
      src={tour.image}
      className="w-full h-[300px] object-cover"
      alt={tour.title}
    />
    <div className={`
      absolute bottom-0 left-0 w-[55%] min-h-[60%] p-4
      ${overlayClasses[color]}
    `}>
      <h3 className="font-heading font-black text-white uppercase">
        {tour.title}
      </h3>
      /* дати, ціна, CTA */
    </div>
  </div>
)
