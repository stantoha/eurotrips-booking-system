⚠
ERRATUM · UX Feedback Session #1 · Пункт I-02
У попередньому фідбеку (файл eurotrips_ux_feedback_frontend.html, секція "Важливі", I-02) я вказав кольори бренду на основі памʼяті, а не реального брендбуку. Це неправильно. Кольори виправлено згідно з PDF.
Порівняння: старі (хибні) vs нові (правильні) значення
ТОКЕН ❌ СТАРЕ (хибне) ✅ НОВЕ (правильне) SWATCHES
brand.blue (PRIMARY) #1B4F9C — взятий з голови #2d70b9 — з PDF брендбуку
→
brand.gold (ACCENT) #F5A623 — взятий з голови #f9c01d — з PDF брендбуку
→
brand.red (DANGER) не вказувався #f0366d — акцентний червоний — →
brand.cyan (SECONDARY) не вказувався #53c7d6 — другорядний синій — →
✅
Шрифти — підтверджені без змін: Druk Text Heavy / Bold для заголовків та Proxima Nova Bold / Medium / Regular для основного тексту — збігаються з брендбуком. Файл brand.ts та tailwind.config.ts у секції "Code Tokens" вже містять правильні значення.
Що потрібно оновити у вже написаному коді
// 1. tailwind.config.ts (якщо вже додані старі кольори) — замінити:
brand: {
  blue:  '#2d70b9', // було #1B4F9C
  gold:  '#f9c01d', // було #F5A623
  // + додати нові:
  red:   '#f0366d',
  cyan:  '#53c7d6',
}

// 2. LoginForm.tsx — кнопка (якщо вже виправляли по I-02):
className="bg-brand-blue hover:bg-brand-blue-dark"
// перевірити що використовується #2d70b9, не #1B4F9C

// 3. statuses.ts STATUS_COLOR_CLASSES — якщо є brand-кольори:
// замінити будь-які посилання на старі hex-значення
